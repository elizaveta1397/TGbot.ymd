# Завершение сессии

1. **Сначала спросить**, кнопкой (AskUserQuestion): «Завершаем работу
   на сегодня?» — с вариантами вроде «Да, заверши сессию» / «Нет, ещё
   не всё» / «Сначала доделаю задачу». Не запускать чек-лист без
   явного подтверждения — фраза-триггер сама по себе не согласие.
2. Если подтвердили — выполнить весь чек-лист из
   `docs/SESSION_WRAPUP.md` по порядку, коротко отчитаться по каждому
   пункту (см. формат отчёта там же). Пункт не к чему применить —
   написать «нечего», не выдумывать работу.
3. Последний шаг чек-листа — коммит и push в git.
4. **`/clear` пользователь выполняет сам** (это команда CLI, не
   инструмент). Напомнить об этом в конце отчёта — самому не пытаться
   завершить или разорвать сессию никаким другим способом.
