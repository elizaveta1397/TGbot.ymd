# Алгоритм завершения сессии

Прогонять в конце каждой сессии Клода над этим ботом — после того, как
основная задача сделана, перед тем как закрывать чат. Если пункт не к
чему применить — так и написать в отчёте («нечего»), не выдумывать
работу.

Это ЗАВЕРШЕНИЕ РАБОЧЕГО ДНЯ, не разрыв сессии: последний шаг —
`/clear` (чистит контекст чата), а не выход/закрытие терминала. CLI-
сессия должна остаться открытой.

## Шаги

1. **Почини то, что сломал за сессию.** Баги, регрессии, конфликты.
   Прогнать весь набор автотестов из корня репозитория:
   ```
   ./venv/bin/python -m pytest tests/ -v
   ```
   Это покрывает все процессы бота разом (cinemalogy, `/start`,
   консультация, unknown — см. `docs/NEW_PROCESS_CHECKLIST.md`), не
   только то, что менялось в этой сессии — цель убедиться, что ничего
   не сломано попутно. Должен быть зелёным целиком; если что-то упало
   — чинить прямо сейчас, а не откладывать в «Известные баги». Там,
   где тестами не покрыто, — хотя бы компиляцией (`python -m
   py_compile`).
2. **Пройди по дифу** (новые/изменённые/удалённые файлы): TODO,
   отладочный код (`print`, `pdb`, `breakpoint`), временные заплатки,
   места без тестов.
3. **Собери, что реально пошло не так** за сессию: упавшие сборки и
   тесты, неверные догадки, обходные пути, непроверенные места. Не
   ограничиваться «всё ок», если по коммитам видно обратное.
4. **Убери мёртвое**, что появилось за эту сессию: неиспользуемые
   функции, файлы, зависимости. Уже задокументированные в CLAUDE.md
   старые баги/мёртвый код — не трогать без явной просьбы Лизы (см.
   раздел «Известные баги» там).
5. **Проверь безопасность и скорость.** Находки чинить сразу же, а не
   откладывать:
   - диф на случайно закоммиченные секреты/токены перед push
     (`git diff origin/main..main | grep -iE "token|secret|password"`);
   - `.env` не должен попасть в git (`git ls-files | grep env` — пусто).
6. **Смоук-чек бота** перед завершением: `sudo /bin/systemctl status
   telegram-bot` (сервис активен, без ошибок в свежем логе) и
   `sudo /usr/bin/journalctl -u telegram-bot -n 25` — если код менялся,
   а сервис не перезапускался после последнего code-change коммита,
   перезапустить (`sudo /bin/systemctl restart telegram-bot`) и
   проверить лог заново.
7. **Ветки кроме main**: что смёржено, что брошено (`git log
   main..origin/<branch>` и обратно). Не удалять без подтверждения —
   только доложить.
8. **Обнови правила проекта** (`CLAUDE.md`) только там, где на это
   есть причина из этой сессии. Корневой файл не раздувай — узкое
   (чек-листы, разовые заметки) выносить отдельными файлами в `docs/`.
9. **Хэндофф**: обнови `HANDOFF.md` в корне репозитория — на чём
   остановились, какой процесс был последним, что осталось
   доделать. Перезаписывается каждую сессию (не копится история).
10. **Открытые вопросы для Лизы**: если что-то требует её решения и
    не решено сейчас — отдельным списком в `HANDOFF.md`, не чинить
    самостоятельно.
11. **Скажи, чего не хватило** из хуков, скиллов и MCP для этой
    сессии. Если хватило — так и написать.
12. **Коммит и push.** Закоммитить всё из шагов выше вместе с рабочими
    изменениями сессии, запушить в `origin` (через `gh`-креды по
    HTTPS, см. `HANDOFF.md`/память — прямой SSH тут не настроен).
13. **`/clear`** — только очистка контекста чата. Сессию не завершать.

## Формат отчёта

По абзацу на каждое: состояние, что изменено, находки, правила,
инструменты, тесты, следующий шаг.
