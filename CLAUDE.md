# Правила работы над этим ботом

Свод правил для любой сессии Клода, работающей в этом репозитории.
Читается автоматически при старте.

## Завершение сессии

Чек-лист и порядок действий на конец рабочего дня — в
`docs/SESSION_WRAPUP.md`, триггер по фразам («спокойной ночи»,
«на сегодня всё» и т.п.) — в `SKILL.md`. Текущий статус («на чём
остановились») — в `HANDOFF.md`, перезаписывается каждую сессию.

## Создание нового процесса

Полный чек-лист (аналитика, уведомления, current_step, работа с
материалами, **обязательные автотесты**) — в
`docs/NEW_PROCESS_CHECKLIST.md`. Читать перед тем, как добавлять
новый хендлер/шаг воронки, а не додумывать по памяти.

## Аналитика — по умолчанию, для каждого нового процесса

Каждый новый хендлер/шаг воронки в этом боте по умолчанию снабжается:

- аналитикой (`add_event` — какой шаг/действие произошло);
- важными деталями в уведомлении админу — строго через
  `bot_services/admin_notifications.py`, не напрямую `bot.send_message`.

Не додумывать самому, какие детали "важные" — если неочевидно, спросить.

## Уведомления админу — тихие по умолчанию

Все уведомления администратору (`bot_services/admin_notifications.py`)
по умолчанию идут **без звука** (`disable_notification=True`).

Со звуком (важные, не трогать без явной просьбы):
- `notify_admin_payment_done` — пользователь подтвердил оплату;
- `notify_care_team` — запрос в отдел Заботы.

Новую функцию уведомления по умолчанию делать тихой; со звуком —
только если Лиза явно скажет, что это важно.

## Разделение ролей

- `ADMIN_ID` — владелец бота, доступ к админ-панели (`handlers/admin.py`).
- `NOTIFY_ADMIN_ID` — куда падают уведомления (сейчас это
  `goncharova_help`, 8673829586). Не путать и не объединять — это
  разные роли, менять их независимо друг от друга.
