## Доступ / как продолжать (не меняется от сессии к сессии)

См. память `server-access-telegram-bot` — ACL, sudoers-путь для
`systemctl` (точное совпадение аргументов, без лишних флагов),
`origin` — HTTPS. Виртуальное окружение `venv/` уже содержит
`gspread`/`google-auth`/`pytest`/`requests` — `pip install -r
requirements-dev.txt` подтянет то же самое с нуля.

Дашборд-артефакт «Проявка»:
https://claude.ai/code/artifact/8340045d-5ef9-4822-941d-0b33a55bb501

Аккаунтная (не репо-специфичная) память `ru-legal-compliance-risks` —
свод штрафов РФ (152-ФЗ/реклама/касса/налоги/авторские права) + шаблон
аудита сайта на 152-ФЗ.
